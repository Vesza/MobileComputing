# MobileComputing
FastSchedule App for Mobile Computing 2026

Um die App starten zu können legen Sie zunächst einen Ordner an in
Ihren Dokumenten namens MobileComputingRepository.

Installieren Sie nun Git.

Installieren Sie nun Node.js (LTS).

Führen Sie GitBash aus.

Navigieren Sie zu Ihrem erstellten Repository.

In der GitBash Konsole geben Sie ein: cd Documents/MobileComputingRepository

Nun geben Sie den Befehl ein: git clone https://github.com/Vesza/MobileComputing.git

Nun eingeben: cd MobileComputing

Nun eingeben: git checkout main

Nun eingeben: git status (muss zeigen, dass Sie sich auf dem main branch befinden)

Nun eingeben: npm install (installiert die notwendigen dependencies)
